# Y2Synth — описание проекта

**Актуально: 18 ноября 2026.** Экспериментальный инструмент для будущего Innioasis Y2. Есть Rust-прототип и отдельный браузерный UI. Аппаратный перенос ещё не проверен.

## Инструменты и генерация

| Дорожка | Модель | Звучание |
| --- | --- | --- |
| DRUMS | drum_kit_rnn / MusicRNN | Девять синтезированных ударных в Rust; KICK/SNARE/HAT в браузере |
| PLUCK | melody_rnn / MusicRNN | Монофоническая мелодия, щипковый тембр |
| PAD | multitrack_chords / MusicVAE | Выбранная полифоническая партия, аддитивный PAD |

Это модели **нотных событий**, не аудио и не эффектов. Все три работают в браузере и Rust. PLUCK и PAD — независимые дорожки, одновременно входят в общий **mono mix → Delay → Reverb → Output**. В Rust внутренние исторические имена TrackId::Synth1/Synth2 сохранены, но CLI использует PLUCK/PAD.

DrumsRNN создаёт ритм с нуля, с одним внутренним тихим bootstrap-шагом. MelodyRNN также не требует пользовательской мелодии. MusicVAE получает один аккорд из C minor; из восьми партий выбирается полифоническая небарабанная. Сетка 96 шагов/такт преобразуется в 16 шагов. Чужой MIDI-тембр не используется: ноты играет наш PAD. Общая гамма C natural minor; смена PAD не переписывает PLUCK.

## Состояние и управление

PLAY воспроизводит последний RAM-снимок, не генерирует заново. AI → Generate Track заменяет только выбранную дорожку после успеха генерации, проверки и подготовки аудио. Ошибка сохраняет предыдущую музыку. В Rust публикация PCM происходит на границе такта; в браузере на той же границе применяются ожидающие ноты.

В USER — отдельные ноты/уровни PLUCK и PAD, параметры Drums. Общие MasterEffects сохраняются вместе с BPM и дорожками. Generate All и сохранение на диск ещё отсутствуют.

CLI: `pluck generate`, `pad generate`, `regenerate`, `play`, `stop`, `fx`. Для нот доступны `pluck|pad demo/show/clear/level/note`. Старые `synth1` команды оставлены как совместимые алиасы; `synth1 pad` теперь создаёт отдельный PAD.

## Две реализации

Rust загружает заранее скачанные checkpoint с диска, инференс работает без сети на control thread. В callback поступает подготовленный PCM; моделей и файлового I/O там нет. Старый процедурный `melody.rs` больше не используется live AI.

Браузер использует официальный Magenta.js в worker. Первый запуск генерации требует интернета для библиотек и весов. Сам DSP реализован отдельно через Web Audio и не обязан звучать точно как Rust. На экране 480×360 — английские меню и click-wheel; настоящий драйвер Y2 не реализован.

## Проверки и следующие шаги

Пользователь ранее подтвердил Rust-тембры и усиленный Delay/Reverb на Mac. Новая версия проверяется GitHub Actions (тесты, сборка live-audio, сверка выбранных траекторий с Magenta.js). Реальная генерация трёх моделей проверена на GitHub Pages.

Ещё нужны прослушивание новых партий на Mac, замеры задержки/CPU/RAM и длительный аудиотест. Для Y2 предстоит определить SoC/ABI, драйверы и доступную память, проверить колесо/экран и пригодность MusicVAE. Это не готовая прошивка. MIDI I/O, стерео, постоянное сохранение и евклидова генерация не реализованы.
