# Архитектура Y2Synth

**Состояние: 17 ноября 2026.** Это архитектура **экспериментального работающего на Mac Studio** аудиодвижка, не готовая прошивка для Innioasis Y2. Пользователь подтвердил работу Synth 1 и одобрил усиленную мастер-цепочку Delay/Reverb. Профилирование и реальная Y2-совместимость ещё впереди.

## Аудиопайплайн

```text
   checkpoint Magenta DrumsRNN       USER-ноты / алгоритмический композитор
                 |                                 |
        Rust LSTM + attention             Synth 1: Pluck / Pad
                 |                                 |
       GeneratedPattern                            |
                 |                                 |
             DrumKit DSP                          |
                 +---------------+-----------------+
                                 |
                      mono mix (control thread)
                                 |
                         Master Delay (BPM)
                                 |
                         Master Reverb
                                 |
                    PreparedLoop (один такт)
                                 |
                     triple_buffer::Input
                                 |
                     triple_buffer::Output
                                 |
                   RealtimePlayer (CPAL)
                                 |
                         Audio Output
```

**Synth 2** предполагается подключить к этому же mix. **Порядок мастер-эффектов неизменен: Delay → Reverb**, оба обрабатывают уже сведённый сигнал. Сейчас весь путь моно; CPAL дублирует один канал на аппаратные выходные каналы.

## Модули Rust

| Файл | Текущая ответственность |
|---|---|
| `lib.rs` | Загрузчик и проверка весовых файлов, экспорт модулей |
| `lstm.rs`, `attention.rs` | Собственный инференс DrumsRNN; 3 LSTM + attention |
| `generation.rs` | Автономная генерация 16 шагов, sampling/argmax, классы/удары |
| `verification.rs`, `bin/verify_reference.rs` | Сопоставление вероятностей Rust и Magenta.js |
| `audio.rs`, `kit.rs`, `dsp.rs` | Синтез ударных и DrumKit |
| `synth1.rs` | Pluck (затухающая струна Karplus–Strong) и Pad (детюнинг/аддитивные гармоники), MIDI-события |
| `melody.rs` | Генерация нот Synth 1: тональность, аккорды, мотивы и ритмический контекст; **не ML** |
| `sequencer.rs` | Предварительная подготовка общего PCM-такта из барабанов и Synth 1 |
| `master_fx.rs` | **Общие** последовательные Delay и Reverb, post-mix, вне callback |
| `project.rs` | `MusicProject<SynthTrack, UnavailableSynth, DrumTrack>`, BPM, мастер-эффекты, источник каждой дорожки и RAM-снимок |
| `application.rs` | Меню → генераторы → рендер → публикация; атомарное сохранение состояния при успехе |
| `ui.rs` | Чистая state machine меню PLAY/USER/AI, без DSP/железа |
| `realtime.rs` | Транспорт, triple buffer, начало следующего такта, плавный переход |
| `bin/live.rs` | macOS CPAL/CLI-адаптер, генерация и управление эффектами на control thread |

`Cargo.toml` содержит CPAL 0.18.2 и triple_buffer 9.0.0 за фичей `live-audio`; зависимости зафиксированы в `Cargo.lock`.

## Мастер-эффекты: общий тракт

`MusicProject.master_fx: MasterEffects` содержит:

- **Delay:** `enabled`, `steps` = 1…8 шестнадцатых нот, `feedback` = 0…0.75, `wet` = 0…1.0. Длина задержки зависит от общего BPM.
- **Reverb:** `enabled`, `size` = 0…1, `damping` = 0…1, `wet` = 0…1.0. Четыре comb-фильтра и две последовательные all-pass стадии, Schroeder-подобная реверберация.
- **По умолчанию:** оба включены; Delay: steps 2, feedback 0.38, wet 0.24; Reverb: size 0.6, damping 0.45, wet 0.2.

В **первой** версии эффекты были слишком тихими. После прослушивания пользователь попросил усилить действие регуляторов. Теперь обработанные сигналы добавляются параллельно к сухому (`dry + wet × effect`), без искусственного приглушения атаки при высоком wet; увеличена доля отражений Reverb. Обновлённое звучание **проверено пользователем на Mac и одобрено**. Защита от чрезмерного пика ограничивает подготовленный такт до 0.85; при насыщении это может уменьшать общую громкость.

Для хвостов Delay/Reverb при повторении короткого такта `render_master_bar` делает **12 предварительных проходов** всего периода через фильтры и публикует последний. Это bounded offline-подход, а не потоковый процессор эффектов с постоянным состоянием; стоимость повторных расчётов на слабом Y2 должна быть измерена. Глобальные настройки обрабатываются после mix и сохраняются в `MusicProject` независимо от текущего набора дорожек.

## Разделение real-time и control

**Control thread** (CLI/будущий обработчик UI) вправе загружать checkpoint, запускать генерацию, вычислять полный такт, микшировать, делать pre-roll мастер-эффектов, выделять память и публиковать новый `PreparedLoop`.

**Audio callback** получает уже подготовленный PCM через `triple_buffer::Output`, управляется `AtomicBool` для play/stop и делает короткий fade/crossfade (~15 мс). Здесь нет вызова DrumsRNN, композитора, master DSP, чтения файлов или явного уничтожения целых PCM-буферов.

Изменение BPM, DrumKit, Synth 1, AI-ритма, параметров Delay/Reverb вызывает новый рендер на control thread; во время воспроизведения смена происходит на границе следующего такта. Публикация не должна портить текущий или последний сохранённый проект при ошибках DSP/аудиопорта. При остановленном транспорте свежий буфер может быть получен сразу.

**Не доказано:** отсутствие xrun на долгой дистанции, измеренная задержка, реальная блокировочная безопасность всех зависимостей/backend. Это будущие задачи измерений, а не следствие самого наличия triple buffer.

## Генерация и структура музыкального проекта

- **DrumsRNN:** pretrained Google Magenta, собственный Rust-инференс, автономный ритм с внутренним тихим bootstrap. Учёт пользовательского заранее записанного грува для генерации отсутствует по требованию проекта.
- **Synth 1:** один трек с пресетом Pluck или Pad, нотами, velocity, длительностями и уровнем; USER-редактирование и отдельная **алгоритмическая** генерация через `Synth1Generator`. Генератор может читать ударные события для синхронизации, но не перезаписывает Drums.
- **AI → Generate Track:** заменяет только выбранную дорожку (Drums либо Synth 1). `GenerateTrack(Synth2)` и `GenerateAll` пока честно возвращают `NotImplemented`.
- **PLAY:** повторное воспроизведение `MusicSession::last_saved`, без нового инференса. В RAM-снимок входят BPM, инструменты, DrumKit, режимы USER/AI и единые мастер-эффекты. При выходе из `live` снимок теряется.
- **CLI:** `synth1 generate`, `synth1 pluck|pad`, `fx`, `fx on|off|reset`, `fx delay ...` и `fx reverb ...`; настоящая дисплейная навигация Y2 пока существует только как концепция и чистая Rust-машина состояний.

Евклидова генерация рисунков высоты/длительности **обсуждалась, но не интегрирована**: не путать с текущим `melody.rs`.

## Изолированный браузерный UI-прототип (18 ноября 2026)

`experiments/ui-prototype/index.html` — одностраничное HTML/CSS/JS приложение без библиотек. Экран **480 × 360 логических пикселей**, как у Y2 по официальной спецификации (2,4″, 4:3), зафиксирован CSS без responsive-масштабирования. GitHub Actions [pages-ui.yml](../.github/workflows/pages-ui.yml) при push в `main` проверяет встроенный JavaScript и native-layout инварианты через `check-ui.mjs`, публикует только статический `index.html` (без Rust и весов). Первый CI-тест **PASS**, первый deploy требует включения GitHub Pages в Settings (пока 404). Оно использует Web Audio API для **приблизительной имитации** DrumKit, Pluck/Pad и общего эффекторного тракта Delay → Reverb, а также имитирует экран, колесо и навигацию PLAY/USER/AI. Его реализация намеренно **не связана с настоящим Rust audio/DSP**: здесь нет компиляции в WASM, вызова DrumsRNN или точной DSP-сверки. Данные остаются в памяти страницы.

Проектируем именно **взаимодействие пользователя**, не доказываем с помощью браузера совместимость со встроенным CPU/дисплеем Y2. После аппаратных измерений возможно повторно использовать навигационную схему в настоящем Y2 UI, адаптируя размеры, ввод и аудиодвижок. [Документация прототипа](../experiments/ui-prototype/README.md).

## Проверки и ограничения

- **DrumsRNN:** подтверждены два численных PASS Rust vs Magenta.js, по 8192 вероятности в каждом тесте с порогом `1e-5` (тихая Argmax, фиксированная ненулевая teacher forcing).
- **Mac live:** пользователь подтвердил работу Synth 1 и затем выразительное звучание общей мастер-цепочки после исправления wet/отражений.
- **Не зафиксированы:** полный лог `cargo test --locked --features live-audio` после последних изменений, отдельное прослушивание `synth1 generate`, xrun/CPU/RAM и тестирование на Y2Linux.
- **План после приезда устройства:** SoC/ABI → Linux и аудиодрайвер → тест audio backend → перенос Rust → профилирование инференса/микса/pre-roll → экран и физическое колесо → долговременное сохранение.
