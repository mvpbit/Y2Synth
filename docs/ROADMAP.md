## Этап 0 — DrumsRNN: эксперимент завершён на Mac

- [x] Исследован checkpoint `drum_kit_rnn_tfjs`: 16 тензоров, 2 967 850 float32-параметров (~11.32 MiB).
- [x] Реализованы собственные загрузчик Rust, 3 LSTM + attention, 512 классов, девять барабанных семейств и автономная генерация 16 шагов без пользовательского входного ритма.
- [x] Сверка Magenta.js `@magenta/music@1.23.1` / WebGL и Rust на **тихой Argmax-траектории**: 16 × 512 = **8192/8192** вероятностей в допуске `1e-5`; максимальная ошибка `1.192092896e-6`, классы 16/16 совпали.
- [x] Вторая сверка на **фиксированной ненулевой teacher-forced истории**: **8192/8192** в допуске `1e-5`; максимальная ошибка `1.072883606e-6`, классы 16/16 совпали (в том числе ненулевые).
- [x] Пользователь прослушал автономно сгенерированный Rust WAV.
- [ ] Другие состояния и TF.js backend не проверены; не утверждать полную эквивалентность всех возможных музыкальных траекторий.

## Этап 2 — Synth 1 / генеративная музыка

- [x] **Pluck** — Karplus–Strong-подобный затухающий струнный голос; **Pad** — многослойный аддитивный тембр с медленной атакой. Не создавать UI выбора square/saw как замену этим музыкальным пресетам.
- [x] USER-трек Synth 1: ноты (pitch, step, length, velocity), уровень, демонстрационные партии, смешивание с Drums.
- [x] Пользователь подтвердил, что **Synth 1 работает и звучит на Mac Studio**.
- [x] `src/melody.rs` — автономная **процедурная (не ML)** генерация музыкальных партий: минорная тональность, мотивы Pluck, аккорды Pad, учёт kick/snare/hat; AI → Generate Track → Synth 1 и `synth1 generate`.
- [x] AI-генерация Synth 1 заменяет только его ноты; пресет/уровень и Drums остаются.
- [ ] Не зафиксирована отдельная слуховая оценка `synth1 generate` после изменений; нет обученной модели мелодий и многоактной композиции.

## Этап 3 — общие мастер-эффекты (звучание подтверждено)

- [x] **Один тракт для всего микса**: Drums + Synth 1 → **Master Delay** → **Master Reverb** → Output.
- [x] Delay синхронизирован с BPM: 1–8 шестнадцатых нот, feedback 0…0.75, wet 0…1.0.
- [x] Reverb: 4 comb + 2 all-pass, size/damping 0…1, wet 0…1.0.
- [x] Обратная связь по первой версии: эффект был слабым. Выполнено усиление отражений и переход на **dry + wet × effect**, исходная атака не глушится; защита от пиков `0.85` остаётся.
- [x] Пользователь подтвердил, что после исправления **Delay и Reverb «теперь всё отлично»**. Это слуховая проверка на Mac, не измерение DSP.
- [x] FX работают после микширования, настройки общие и сохраняются вместе с последним RAM-проектом; изменение параметров и BPM запускает offline re-render вне callback.
- [x] Добавлены unit-тесты dry bypass, времени эха, реверберационного хвоста, степени слышимости по wet, валидации и отката при ошибке.
- [ ] Полный последний прогон тестов отдельно не зафиксирован; на Y2 следует оценить цену **12 предварительных прогонов** FX через каждый такт.
- [ ] Сейчас выход моно; стереореверберация и более широкий пространственный тракт возможны позже.
