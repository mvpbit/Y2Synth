# Y2Synth — меню PLAY/USER/AI (концепция и текущий CLI)

**Актуально: 18 ноября 2026.** Машина состояний `src/ui.rs` и работающий на Mac интерфейс CLI уже есть. **Аппаратные экраны, жесты колеса и кнопки Innioasis Y2 ещё не реализованы и не проверены на устройстве.** Все последующие схемы колеса — согласованный черновик, а не подтверждённая раскладка железа.

## Главный принцип

На главном экране **один PLAY**. Его действие — воспроизвести **последний сохранённый в RAM музыкальный проект**, без обязательной новой генерации. Центр колеса должен открывать настройки, BACK — возвращать на уровень выше.

```text
PLAY
├─ PLAY → воспроизвести последнее состояние
└─ CENTER → PLAY SETTINGS
   ├─ USER
   │  ├─ PLUCK → ноты и уровень (браузер и Rust)
   │  ├─ PAD   → аккорды и уровень (браузер и Rust)
   │  └─ DRUMS   (параметры DrumKit; CLI реализован)
   └─ AI
      ├─ GENERATE ALL (пока недоступен)
      └─ GENERATE TRACK
         ├─ PLUCK → новая мелодия (MelodyRNN)
         ├─ PAD   → новые аккорды (MusicVAE)
         └─ DRUMS   → Magenta DrumsRNN (в коде)
```

**MASTER FX** — отдельные параметры **всего проекта**, а не дорожек; в текущем Mac-прототипе доступны через CLI. Их место и жесты настройки в будущем экранном меню Y2 ещё предстоит определить, не меняя основной принцип «один PLAY».

## Что реально работает через Application Controller

- `Command::PlayLast`: повторно готовит сохранённый mix с текущими FX, публикует его и начинает воспроизведение **без генерации**.
- `Command::GenerateTrack(Drums)`: DrumsRNN генерирует новую барабанную дорожку, не трогая Synth 1 или master FX.
- `dispatch_neural` маршрутизирует `GenerateTrack(Synth1)` к PLUCK/MelodyRNN, `GenerateTrack(Synth2)` к PAD/MusicVAE. Меняются только ноты выбранной дорожки, её уровень сохраняется.
- `EditUserTrack(Synth1/Synth2)`: CLI-редакторы PLUCK/PAD. `EditUserTrack(Drums)`: настройки DrumKit.
- `GenerateAll` пока NotImplemented.
- Успешные изменения BPM, дорожек, DrumKit и master FX обновляют RAM-снимок только после подготовки и публикации. Ошибка сохраняет current и last_saved.

`src/ui.rs` — чистая state machine: `InputEvent` → `MenuController` → `Command`. В ней нет работы с DSP, моделями или драйверами. Физическое колесо пока заменено консольными `center`, `next`, `prev`, `back`, `wheel-play`.

## Общие Delay и Reverb в CLI

Тракт **Drums + PLUCK + PAD → Delay → Reverb → Output**. Настройки по умолчанию включены, сохраняются с общим проектом в RAM:

```text
fx                         # показать общие настройки
fx off                     # полностью обойти оба эффекта
fx on                      # включить оба с прежними значениями
fx reset                   # вернуть параметры по умолчанию
fx delay steps 4           # четвертная нота при любом BPM
fx delay feedback 0.55
fx delay wet 1.0
fx reverb size 0.9
fx reverb damping 0.5
fx reverb wet 1.0
```

Для каждого эффекта работают отдельные `fx delay on|off` и `fx reverb on|off`. После обратной связи пользователя мокрая составляющая теперь добавляется параллельно к сухому звуку; оба `wet` поддерживают `0…1.0`. **Усиленная версия услышана пользователем на Mac и одобрена.**

## Как проверить симуляцию меню

Внутри запущенного `live`, из главного экрана (у новой сессии `MenuController` начинается с PLAY):

```text
menu          # Home: PLAY
center        # PLAY SETTINGS; USER выбран по умолчанию
next          # выбрать AI
center        # войти в AI menu
next          # GENERATE TRACK
center        # выбрать дорожку (по умолчанию PLUCK)
center        # сгенерировать ТОЛЬКО PLUCK
back          # AI menu
back          # PLAY SETTINGS
back          # Home
wheel-play    # сыграть последнее сохранённое без перегенерации
```

Более простой путь без эмуляции колеса: `play`, `regenerate`, `pluck generate`, `pad generate`, `pluck demo`, `pad demo`, `fx`, `bpm 90`, `status`, `stop`, `quit`.

## HTML/Web Audio UI LAB (18 ноября 2026)

**Последнее изменение браузерного меню:** HOME содержит только PLAY/PAUSE и подсказку OK → settings. В настройках пять прямых пунктов: **DRUMS → PAD → PLUCK → FX → TEMPO**. Промежуточного меню инструментов нет; BACK возвращает прямо в PLAY SETTINGS. USER, демо и редактирование шагов удалены; стартовые партии пусты. PLUCK/PAD сохраняют уровни. Экран эффектов и его обработка не менялись. Схема USER/AI выше теперь относится к историческому Rust-меню; браузер использует эту упрощённую структуру.

В дополнение к концепции настоящего Y2 создан **[экранный прототип](../experiments/ui-prototype/index.html)** и [инструкция](../experiments/ui-prototype/README.md). Область экрана проектируется в **реальном разрешении Innioasis Y2 — 480×360 px (2,4″, 4:3)** согласно [официальной спецификации](https://www.innioasis.com/a/docs/y2/specifications). Никаких адаптивных изменений самой сетки при узком окне браузера. В макете есть интерактивное **сенсорное кольцо** Y2 с интегрированными четырьмя кнопками (сверху Return, слева Previous, справа Next, снизу Play/Pause с длинным нажатием Stop) и центральным OK. Круговое перетаскивание/касание листает пункты меню, а после нажатия OK на числе меняет значение; повторное OK завершает редактирование. В браузере поддерживаются мышь, touch, wheel/trackpad и клавиатура. Раскладка основана на [официальном описании устройства](https://www.innioasis.com/a/docs/y2/device-overview), реальные события аппаратного колеса на устройстве ещё не исследованы. 16-шаговые партии остаются внутри секвенсора; сетка не отображается. MASTER FX сохранён.

Для веб-прототипа добавлен [GitHub Pages workflow](../.github/workflows/pages-ui.yml). GitHub Pages уже активирован, [Y2Synth UI Lab](https://mvpbit.github.io/Y2Synth/) работает. Новые версии HTML в `main` автоматически проверяются и публикуются; проверка колеса включает круговой жест, режим изменения BPM, кнопки и STOP.

**Решение по дорожкам (18 ноября): названия инструментов — только PLUCK и PAD.** В Web Audio прототипе обе дорожки реализованы независимо: `state.pluck` и `state.pad`, страницы `pluck`/`pad`, регуляторы `pluckLevel`/`padLevel`; у каждой свои AI-ноты, уровень и генерация. Переключатель Pluck/Pad из меню USER удалён. В Rust теперь также две реальные дорожки: исторические TrackId::Synth1/Synth2 соответствуют PLUCK/PAD. CLI показывает названия инструментов.

Веб-прототип **звучит через Web Audio API**. Генерация использует официальный Magenta.js в Web Worker: DRUMS=drum_kit_rnn, PLUCK=melody_rnn, PAD=multitrack_chords. Модели загружаются по запросу; первый запуск требует сети. При PLAY результат применяется на границе такта, ошибки сохраняют прежнюю партию. Web Audio DSP и ConvolverNode отличаются от Rust DSP. Генерация всех трёх моделей проверена на опубликованной странице; новая музыка ещё требует пользовательского прослушивания.

## Тональность PAD и зависимый PLUCK

В PLAY SETTINGS сначала выбрать PAD → GENERATE CHORDS: случайно выбирается мажорная/минорная тональность, её имя появляется у PAD. После этого PLUCK → GENERATE MELODY создаёт мелодию с согласованием под PAD. Без PAD эта кнопка недоступна. Повторная генерация PAD выбирает новую тональность и подстраивает уже существующий PLUCK; во время PLAY обе дорожки меняются вместе на границе такта. Аналогичный порядок в Rust CLI: `pad generate`, затем `pluck generate`. MASTER FX не менялся.

## Что предстоит решить на Y2

- Назначение физических жестов колеса/центра/BACK и отображение режимов на реальном дисплее.
- Размещение **MASTER FX** в экранном интерфейсе, отображение пресетов, уровня и параметров генератора.
- Поведение PLAY при stop/pause и при пустом проекте; визуальная обратная связь о генерации/ошибках.
- Постоянное сохранение проекта на диск (сейчас только RAM) и способ редактирования/проигрывания нескольких тактов.
- Generate All и управление многотактовыми партиями.

Звучание Mac-прототипа подтверждено; полноценный тест навигации на реальном Y2 и длинная проверка CoreAudio ещё не выполнены.
