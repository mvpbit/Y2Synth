# Y2Synth — меню PLAY/USER/AI (концепция и текущий CLI)

**Актуально: 17 ноября 2026.** Машина состояний `src/ui.rs` и работающий на Mac интерфейс CLI уже есть. **Аппаратные экраны, жесты колеса и кнопки Innioasis Y2 ещё не реализованы и не проверены на устройстве.** Все последующие схемы колеса — согласованный черновик, а не подтверждённая раскладка железа.

## Главный принцип

На главном экране **один PLAY**. Его действие — воспроизвести **последний сохранённый в RAM музыкальный проект**, без обязательной новой генерации. Центр колеса должен открывать настройки, BACK — возвращать на уровень выше.

```text
PLAY
├─ PLAY → воспроизвести последнее состояние
└─ CENTER → PLAY SETTINGS
   ├─ USER
   │  ├─ SYNTH 1 (Pluck/Pad, ноты, уровень; CLI реализован)
   │  ├─ SYNTH 2 (пока недоступен)
   │  └─ DRUMS   (параметры DrumKit; CLI реализован)
   └─ AI
      ├─ GENERATE ALL (пока недоступен)
      └─ GENERATE TRACK
         ├─ SYNTH 1 → алгоритмическая мелодия/аккорды (в коде)
         ├─ SYNTH 2 → пока недоступен
         └─ DRUMS   → Magenta DrumsRNN (в коде)
```

**MASTER FX** — отдельные параметры **всего проекта**, а не дорожек; в текущем Mac-прототипе доступны через CLI. Их место и жесты настройки в будущем экранном меню Y2 ещё предстоит определить, не меняя основной принцип «один PLAY».

## Что реально работает через Application Controller

- `Command::PlayLast`: повторно готовит сохранённый mix с текущими FX, публикует его и начинает воспроизведение **без генерации**.
- `Command::GenerateTrack(Drums)`: DrumsRNN генерирует новую барабанную дорожку, не трогая Synth 1 или master FX.
- `Command::GenerateTrack(Synth1)`: `ApplicationController::dispatch_with_synth` вызывает `Synth1Generator`, сохраняет Pluck/Pad и уровень, но заменяет ноты. Это **процедурный музыкальный алгоритм**, не обученная нейросеть. Drums и master FX не заменяются.
- `EditUserTrack(Synth1)`: CLI-подсказки для выбора Pluck/Pad, уровня и нот. `EditUserTrack(Drums)`: настройки DrumKit.
- `GenerateTrack(Synth2)`, `GenerateAll`, редактор Synth 2: **NotImplemented**, не изменяют проект.
- Любое успешное изменение BPM, DrumKit, Synth 1, барабанного паттерна или master FX обновляет `MusicSession::last_saved` **только в RAM**. При ошибке генерации/подготовки/публикации предыдущий снимок сохраняется.

`src/ui.rs` — чистая state machine: `InputEvent` → `MenuController` → `Command`. В ней нет работы с DSP, моделями или драйверами. Физическое колесо пока заменено консольными `center`, `next`, `prev`, `back`, `wheel-play`.

## Общие Delay и Reverb в CLI

Тракт **Drums + Synth 1 → Delay → Reverb → Output**. Настройки по умолчанию включены, сохраняются с общим проектом в RAM:

```text
fx                         # показать общие настройки
fx off                     # полностью обойти оба эффекта
fx on                      # включить оба с прежними значениями
fx reset                   # вернуть параметры по умолчанию
fx delay steps 4           # четвертная нота при любом BPM
fx delay feedback 0.55
fx delay wet 1.0
fx reverb size 0.9
fx reverb damping 0.5
fx reverb wet 1.0
```

Для каждого эффекта работают отдельные `fx delay on|off` и `fx reverb on|off`. После обратной связи пользователя мокрая составляющая теперь добавляется параллельно к сухому звуку; оба `wet` поддерживают `0…1.0`. **Усиленная версия услышана пользователем на Mac и одобрена.**

## Как проверить симуляцию меню

Внутри запущенного `live`, из главного экрана (у новой сессии `MenuController` начинается с PLAY):

```text
menu          # Home: PLAY
center        # PLAY SETTINGS; USER выбран по умолчанию
next          # выбрать AI
center        # войти в AI menu
next          # GENERATE TRACK
center        # выбрать дорожку (по умолчанию Synth 1)
center        # сгенерировать ТОЛЬКО Synth 1
back          # AI menu
back          # PLAY SETTINGS
back          # Home
wheel-play    # сыграть последнее сохранённое без перегенерации
```

Более простой путь без эмуляции колеса: `play`, `regenerate`, `synth1 pluck`, `synth1 pad`, `synth1 generate`, `fx`, `bpm 90`, `status`, `stop`, `quit`.

## Что предстоит решить на Y2

- Назначение физических жестов колеса/центра/BACK и отображение режимов на реальном дисплее.
- Размещение **MASTER FX** в экранном интерфейсе, отображение пресетов, уровня и параметров генератора.
- Поведение PLAY при stop/pause и при пустом проекте; визуальная обратная связь о генерации/ошибках.
- Постоянное сохранение проекта на диск (сейчас только RAM) и способ редактирования/проигрывания нескольких тактов.
- Реализация Synth 2, Generate All и возможной обученной генеративной модели мелодий.

Звучание Mac-прототипа подтверждено; полноценный тест навигации на реальном Y2 и длинная проверка CoreAudio ещё не выполнены.
