# Y2SYNTH

Экспериментальный карманный синтезатор на базе Innioasis Y2. Планируемые возможности: два синтезатора, драм-машина и локальный AI-помощник.

Проект находится на раннем экспериментальном этапе. Устройство ещё не получено, интерфейс не утверждён, аудиодвижок и прошивка отсутствуют. На Mac подтверждены загрузка весов Magenta и автономная генерация через Magenta.js; в экспериментальной ветке проверены Rust-загрузчик весов, 3 LSTM-слоя и первый шаг attention. Экспериментальный Rust-генератор уже успешно создал 16-шаговый паттерн на Mac (40,2 мс на один тестовый запуск). Многошаговая численная эквивалентность Magenta.js пока не проверена. Совместимость с Y2 и аппаратные характеристики не проверены.

## Планируемая технологическая основа

- Rust — основной язык реализации.
- Embedded Linux на основе Y2Linux — предполагаемая среда устройства.
- Готовые веса Magenta DrumsRNN — кандидат для автономной генерации новых барабанных паттернов **без исходного грува пользователя**. Внутренний служебный стартовый шаг модели не является пользовательским паттерном.
- Mac — среда первоначальной разработки и тестирования переносимых компонентов.

Этот выбор предварительный. Возможность исполнения DrumsRNN, совместимость Y2Linux и пригодность устройства для аудио в реальном времени предстоит подтвердить. Наличие готовых весов само по себе не гарантирует возможность запуска на Y2.
