# Y2Synth

**Y2Synth** — экспериментальный карманный музыкальный инструмент на базе Innioasis Y2. Планируемые части: два синтезатора, драм-машина, секвенсор и локальная AI-генерация барабанных ритмов.

Основная разработка ведётся на **Rust** и сейчас проверяется на Mac. Будущая платформа — Linux на Innioasis Y2 (ориентир Y2Linux); сборка и работа на самом устройстве **пока не подтверждены**.

## Текущее состояние

- **Работает на Mac:** загрузка весов Magenta DrumsRNN, собственный Rust-инференс (3 LSTM + attention), автономная генерация 16 шагов и тестовый WAV-рендерер барабанов. Пользователь подтвердил прослушивание WAV.
- **Подтверждена полная численная сверка одной детерминированной траектории:** Rust vs Magenta.js `@magenta/music@1.23.1` (WebGL) на Mac Studio: **PASS**, все **16 × 512 = 8192 вероятностей** в пределах `1e-5`, максимальная абсолютная ошибка `1.192092896e-6`, средняя `1.529578996e-9`, RMS `2.754894988e-8`; выбранные классы совпали на 16/16 шагах. Это **тихая Argmax-траектория (класс 0 на каждом шаге)**, а не проверка всех возможных ритмов. Подробности в `docs/research/magenta-drumsrnn.md`.
- **Первый live-прототип работает на Mac (подтверждено пользователем):** `src/sequencer.rs` и интерактивный `bin/live.rs` с CPAL/CoreAudio. Предусмотрены команды `play`, `stop`, `bpm`, `regenerate`, `quit`; отдельное тестирование каждой команды, переключений и длительной работы ещё необходимо. Аудио читается из предварительно рассчитанных PCM-буферов, модель не работает в audio callback.
- **Новый код, требует проверки на Mac:** `application.rs` связывает меню PLAY → USER/AI с DrumsRNN и воспроизведением. Команда AI → Generate Track → Drums генерирует реальный барабанный такт, PLAY воспроизводит последний RAM-снимок без повторной генерации; `live.rs` поддерживает эмуляцию колеса `center/next/prev/back/wheel-play`. Также добавлены настройки `DrumKit` (`level/tone/decay`).
- **Synth 1 реализован в коде, но ещё не прослушан на Mac:** два инструментальных пресета **Pluck** (модель затухающей струны) и **Pad** (аддитивный полифонический тембр с движущимися обертонами), 16-шаговые нотные события, отдельный уровень и смешивание с AI-Drums в одном подготовленном такте. В live CLI доступны `synth1 pluck`, `synth1 pad`, `synth1 show`, `synth1 clear`, `synth1 level 0.7` и `synth1 note 0 60 2`. Отдельной AI-генерации синтезатора пока нет.
- **Генерация мелодий Synth 1 добавлена в `main`, ещё не проверена на Mac:** команда `synth1 generate` и AI → Generate Track → Synth 1 создают новые ритмические мелодии Pluck либо гармонические фразы Pad с учётом существующих барабанов. Это **музыкальный алгоритм, не обученная нейросеть**; выбранный тембр и громкость сохраняются, барабанная дорожка не заменяется.
- **Не реализованы:** Synth 2, обученная ML-модель для мелодий, Generate All, аппаратный экран и кнопки Y2, долговременное хранение, прошивка Y2 и production audio.

Модель генерирует барабаны **без ритма, заранее введённого пользователем**. Внутренний служебный тихий начальный шаг не является пользовательским паттерном.

## Быстрый запуск на Mac

Нужны Rust/Cargo, а для модели — локальные файлы checkpoint. При первом запуске:

```bash
bash experiments/drumsrnn/download-model.sh
cargo test --manifest-path experiments/drumsrnn/rust/Cargo.toml
```

Сгенерировать и прослушать ритм (из корня репозитория):

```bash
cargo run --release \
  --manifest-path experiments/drumsrnn/rust/Cargo.toml \
  --bin generate -- --steps 16 --temperature 1.2 \
  --wav /tmp/y2synth-groove.wav --bpm 120

afplay /tmp/y2synth-groove.wav
```

Это офлайн WAV-просмотр. Для интерактивного live-прототипа на macOS:

```bash
cargo run --release --manifest-path experiments/drumsrnn/rust/Cargo.toml \
  --features live-audio --bin live -- --bpm 120 --temperature 1.2
```

В появившейся консоли: `play`, `stop`, `bpm 140`, `regenerate`, `kit`, `menu`, `center`, `next`, `prev`, `back`, `wheel-play`, `status`, `quit`. Пользователь подтвердил работу предыдущего live-аудиопрототипа на Mac; **последняя интеграция меню и DSP требует новой сборки и прослушивания**. Генерация AI и подготовка буфера выполняются вне аудиопотока; смена запланирована на границе такта. В новой версии аудиопоток получает новые буферы через lock-free triple buffering и атомарное управление транспортом: в нашем callback нет `std::mpsc`, выделения или освобождения буферов. Triple-buffer audio ранее проверен пользователем на Mac; интеграция Application Controller и новый DSP пока не проверены, а xrun/latency и гарантии реального времени потребуют отдельного тестирования.

**Зависимости:** CPAL 0.18.2 и triple_buffer 9.0.0 уже внесены в `Cargo.lock` в `main`. Новые изменения Application Controller не добавляют зависимости; сборки можно выполнять с `--locked`. Веса модели и аудиофайлы в Git не добавлять.

### Численная проверка ненулевой истории DrumsRNN

В дополнение к подтверждённой сверке 8192 вероятностей на тихой Argmax-траектории добавлена **диагностическая проверка teacher forcing**: отдельная страница `experiments/drumsrnn/teacher-forcing.html` создаёт эталон Magenta.js по фиксированным **ненулевым барабанным входам**, а тот же `verify_reference` сравнивает 16 × 512 значений с Rust. **PASS подтверждён на Mac Studio (2026-11-17):** все **8192 вероятности** уложились в допуск `1e-5`, максимум `1.072883606e-6`, средняя ошибка `2.160613040e-9`, RMS `2.886892393e-8`, **0/16** несовпадающих Argmax-классов (присутствуют ненулевые выбранные классы). Это проверка одной фиксированной истории, не всех возможных траекторий. Обычная автономная AI-генерация не менялась. Команды и ограничения описаны в [исследовании DrumsRNN](docs/research/magenta-drumsrnn.md).


### Общая мастер-цепочка эффектов (первый код, Mac-проверка впереди)

Добавлены два **мастер-эффекта**: `Drums + Synth 1 → Delay → Reverb → Output`. Delay синхронизируется с темпом и регулируется параметрами `steps`, `feedback`, `wet`; Reverb — `size`, `damping`, `wet`. Команды live-прототипа: `fx`, `fx on/off/reset`, `fx delay steps 4`, `fx delay feedback 0.35`, `fx delay wet 0.3`, `fx reverb size 0.8`, `fx reverb damping 0.5`, `fx reverb wet 0.35`. Это настройки **всего проекта**, а не отдельные эффекты каждого трека. Общий DSP выполняется до передачи в аудио callback. Код и тесты добавлены в `main`, сборка и звучание этой версии на Mac ещё не подтверждены.
