# Y2Synth

**Y2Synth** — экспериментальный карманный музыкальный инструмент для будущего запуска на Innioasis Y2. На Mac Studio уже звучит прототип на Rust: автономная AI-драм-машина, независимые **PLUCK** и **PAD**, секвенсор и общая мастер-цепочка **Delay → Reverb**.

**Статус на 18 ноября 2026 года:** выбранные модели подключены в браузере и Rust: **drums → drum_kit_rnn, pluck → melody_rnn, pad → multitrack_chords**. [GitHub Actions](https://github.com/mvpbit/Y2Synth/actions/runs/44209622695) подтвердил 118 Rust-тестов и совпадение 16 MelodyRNN / 512 MusicVAE Argmax-токенов на тестовых траекториях; браузерная генерация всех трёх инструментов проверена на опубликованной странице. Пользователь ранее прослушал тембры и мастер-эффекты на Mac. Новая трёхдорожечная Rust-версия ещё требует прослушивания на Mac; запуск и ресурсы Innioasis Y2 не проверены.

## Что реализовано

- **DrumsRNN:** собственный Rust-загрузчик весов Google Magenta, три LSTM-слоя с attention, 512 классов (9 типов ударных), автономная генерация 16 шагов без пользовательского начального ритма. Checkpoint хранится локально, вне Git.
- **Численная сверка:** Rust и Magenta.js `@magenta/music@1.23.1` / WebGL подтвердили **PASS** по всем **8192 вероятностям** при пороге `1e-5` на *двух* разных диагностических траекториях: тихая Argmax (максимальная ошибка `1.192092896e-6`) и фиксированная ненулевая teacher-forced (`1.072883606e-6`). В обоих тестах `0/16` несовпадающих классов. Это не доказательство эквивалентности модели на всех возможных входах.
- **PLUCK / PAD:** два независимых инструмента с собственными нотами и уровнем: щипковая струна Karplus–Strong и аддитивный полифонический Pad.
- **Нейросетевая генерация:** PLUCK получает монофоническую партию MelodyRNN. PAD использует аккордово-условный MusicVAE: из восьми партий выбирается полифоническая небарабанная дорожка; её MIDI-тембр заменяется нашим PAD. PAD при каждой генерации выбирает случайную тональность (12 тоник, мажор/минор). Сначала генерируется PAD, затем PLUCK: опорные ноты мелодии согласуются с звучащими голосами PAD, проходящие — с гаммой. При смене PAD существующий PLUCK подстраивается автоматически; пара меняется на границе такта. Длина — 16 шагов. Модели создают ноты, а не аудио или эффекты.
- **Rust-инференс:** `src/neural.rs` реализует двухслойный MelodyRNN и иерархический декодер MusicVAE; загрузчик поддерживает uint8/uint16-квантизацию. Веса загружаются с диска по запросу, ненужные энкодеры PAD не удерживаются в памяти. Старый `melody.rs` остаётся исследовательским процедурным модулем и больше не используется live AI.
- **Общие мастер-эффекты:** строго **(Drums + PLUCK + PAD) → Delay → Reverb → выход**. Delay синхронизирован с BPM (`steps` в 1/16, `feedback`, `wet`); Reverb — comb/all-pass, `size`, `damping`, `wet`. Оба эффекта используют параллельное добавление wet к dry, `wet` от `0` до `1.0`, защита пика до `0.85`. **Усиленная версия обоих эффектов проверена пользователем на слух и одобрена.**
- **Транспорт и музыкальный проект:** CPAL/CoreAudio, lock-free triple buffer, публикация готового такта на его границе, PLAY/STOP/BPM, отдельные дорожки USER/AI, снимок последнего проекта **в RAM** (BPM, DrumKit, партии, параметры мастер-эффектов). В callback нет инференса или подготовки полного PCM-такта. Сейчас микс и мастер-эффекты **моно**.

## Быстрый запуск на Mac

Из корня репозитория:

```bash
git pull --ff-only
# Скачать выбранные checkpoints (веса не входят в Git):
for model in drum_kit_rnn melody_rnn multitrack_chords; do
  bash experiments/drumsrnn/download-model.sh "$model"
done

cargo test --locked --manifest-path experiments/drumsrnn/rust/Cargo.toml --features live-audio

cargo run --release --locked \
  --manifest-path experiments/drumsrnn/rust/Cargo.toml \
  --features live-audio --bin live -- \
  --bpm 120 --temperature 1.2
```

В появившейся консоли `y2>`:

```text
play
regenerate
pad generate
pluck generate
pluck show
pad show
fx
fx off
fx on
fx delay steps 4
fx delay feedback 0.55
fx delay wet 1.0
fx reverb size 0.9
fx reverb damping 0.5
fx reverb wet 1.0
fx reset
status
stop
quit
```

Изменения звука подготавливаются на управляющем потоке и вступают в силу на границе такта. `fx off` — обход обоих эффектов, `fx on` — включение с сохранёнными значениями, `fx reset` — заводские параметры. Параметры цепочки применяются **к общему миксу**, не по отдельности к барабанам или синтезатору.

## Браузерный прототип интерфейса (18 ноября 2026)

Для предварительного проектирования интерфейса **до получения Y2** добавлен [HTML/Web Audio UI prototype](experiments/ui-prototype/README.md) и [index.html](experiments/ui-prototype/index.html) с нативным дисплеем **480 × 360 px (2,4″, 4:3)** по [официальным характеристикам Innioasis](https://www.innioasis.com/a/docs/y2/specifications), общим **сенсорным click-wheel** Y2 (Return / Previous / Next / Play-Pause / OK) с настоящим вращением мышью/пальцем, USER/AI, 16-шаговой сеткой, Pluck/Pad и общей цепочкой Delay → Reverb. Экран не масштабируется responsive-правилами: проектируем именно фиксированную 480×360 логическую сетку.

Это **отдельный Web Audio звуковой движок** и официальный Magenta.js в Web Worker. Нейросети загружаются с Google Storage при первой генерации, библиотеки — с jsDelivr. Для первого использования нужен интернет. Инференс не блокирует UI; новые партии во время воспроизведения применяются на границе такта. Ошибка оставляет предыдущие ноты. Это не порт Rust DSP и не аппаратная прошивка.

Добавлен [GitHub Actions deploy workflow](.github/workflows/pages-ui.yml): при изменениях UI в `main` он автоматически проверяет JavaScript и фиксированный размер дисплея, затем развёртывает статический HTML на GitHub Pages. **Pages уже активирован, статические и интерактивные smoke-проверки колеса проходят в GitHub Actions**, интерфейс доступен: [https://mvpbit.github.io/Y2Synth/](https://mvpbit.github.io/Y2Synth/). Локально: `python3 -m http.server 8765 --bind 127.0.0.1`, затем `http://127.0.0.1:8765/experiments/ui-prototype/index.html`.

## Что осталось

**Следующий шаг:** прослушать новые партии, измерить задержку генерации и память. После приезда Y2 проверить SoC/ABI, Linux-аудио, колесо/дисплей и ресурсы моделей. Оптимизация и пригодность MusicVAE для Y2 ещё не подтверждены.

Пока отсутствуют AI Generate All, интерфейс на реальном дисплее Y2, сохранение проектов на диск и доказанная production real-time безопасность. Евклидов секвенсор для высоты/длительности обсуждался, **но в работающий тракт не интегрирован**.
