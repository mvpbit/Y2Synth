# Y2Synth

**Y2Synth** — экспериментальный карманный музыкальный инструмент для будущего запуска на Innioasis Y2. На Mac Studio уже звучит прототип на Rust: автономная AI-драм-машина, первый синтезатор **Pluck / Pad**, секвенсор и общая мастер-цепочка **Delay → Reverb**.

**Статус на 17 ноября 2026 года:** пользователь подтвердил работу Synth 1 и прослушал усиленную версию обоих мастер-эффектов («всё отлично»). Работу на самом Innioasis Y2 пока **не проверяли**: разработку на Mac приостановили до приезда устройства. Отдельных отчётов о нагрузке, xrun, длительном тесте и полном прогоне `cargo test` для последней версии пока нет.

## Что реализовано

- **DrumsRNN:** собственный Rust-загрузчик весов Google Magenta, три LSTM-слоя с attention, 512 классов (9 типов ударных), автономная генерация 16 шагов без пользовательского начального ритма. Checkpoint хранится локально, вне Git.
- **Численная сверка:** Rust и Magenta.js `@magenta/music@1.23.1` / WebGL подтвердили **PASS** по всем **8192 вероятностям** при пороге `1e-5` на *двух* разных диагностических траекториях: тихая Argmax (максимальная ошибка `1.192092896e-6`) и фиксированная ненулевая teacher-forced (`1.072883606e-6`). В обоих тестах `0/16` несовпадающих классов. Это не доказательство эквивалентности модели на всех возможных входах.
- **Synth 1:** два полноценных тембра: **Pluck** (затухающая модель струны Karplus–Strong) и **Pad** (слегка расстроенные аддитивные голоса с медленными огибающими). Нотные события, уровень, воспроизведение отдельно или вместе с барабанами. **Звучание подтверждено пользователем на Mac.**
- **Генерация партий Synth 1:** отдельный детерминированный алгоритмический композитор (`src/melody.rs`) создаёт мотивы Pluck и аккорды Pad, учитывая ритмические акценты барабанов. Команда `synth1 generate` и AI → Generate Track → Synth 1 добавлены в live CLI. **Это не обученная нейросеть.** Отдельный отчёт о качестве сгенерированных мелодий не зафиксирован.
- **Общие мастер-эффекты:** строго **(Drums + Synth 1) → Delay → Reverb → выход**. Delay синхронизирован с BPM (`steps` в 1/16, `feedback`, `wet`); Reverb — comb/all-pass, `size`, `damping`, `wet`. Оба эффекта используют параллельное добавление wet к dry, `wet` от `0` до `1.0`, защита пика до `0.85`. **Усиленная версия обоих эффектов проверена пользователем на слух и одобрена.**
- **Транспорт и музыкальный проект:** CPAL/CoreAudio, lock-free triple buffer, публикация готового такта на его границе, PLAY/STOP/BPM, отдельные дорожки USER/AI, снимок последнего проекта **в RAM** (BPM, DrumKit, партии, параметры мастер-эффектов). В callback нет инференса или подготовки полного PCM-такта. Сейчас микс и мастер-эффекты **моно**.

## Быстрый запуск на Mac

Из корня репозитория:

```bash
git pull --ff-only
# Если checkpoint ещё не скачан:
bash experiments/drumsrnn/download-model.sh

cargo test --locked --manifest-path experiments/drumsrnn/rust/Cargo.toml --features live-audio

cargo run --release --locked \
  --manifest-path experiments/drumsrnn/rust/Cargo.toml \
  --features live-audio --bin live -- \
  --bpm 120 --temperature 1.2
```

В появившейся консоли `y2>`:

```text
play
regenerate
synth1 pluck
synth1 generate
synth1 pad
synth1 generate
fx
fx off
fx on
fx delay steps 4
fx delay feedback 0.55
fx delay wet 1.0
fx reverb size 0.9
fx reverb damping 0.5
fx reverb wet 1.0
fx reset
status
stop
quit
```

Изменения звука подготавливаются на управляющем потоке и вступают в силу на границе такта. `fx off` — обход обоих эффектов, `fx on` — включение с сохранёнными значениями, `fx reset` — заводские параметры. Параметры цепочки применяются **к общему миксу**, не по отдельности к барабанам или синтезатору.

## Браузерный прототип интерфейса (18 ноября 2026)

Для предварительного проектирования интерфейса **до получения Y2** добавлен самостоятельный [HTML/Web Audio UI prototype](experiments/ui-prototype/README.md) и [index.html](experiments/ui-prototype/index.html): экран, колесо с SELECT, PLAY/BACK, меню USER/AI, 16-шаговый индикатор/редактор барабанов, Synth 1 Pluck/Pad и единая управляемая мастер-цепочка Delay → Reverb.

Это **отдельная браузерная звуковая имитация**, не JavaScript-порт Rust, не Magenta.js DrumsRNN и не аппаратная прошивка. Задача — проверить эргономику меню и найти форму UI; браузерный запуск и качество звучания прототипа пока не подтверждены пользователем.

Из корня проекта: `python3 -m http.server 8765 --bind 127.0.0.1`, затем открыть `http://127.0.0.1:8765/experiments/ui-prototype/index.html` и нажать PLAY.

## Что осталось

**До появления Y2:** сохранён рабочий Mac-прототип и исследовательские результаты; нет необходимости начинать новые функции. **После приезда Y2:** выяснить SoC/ABI и доступную память, загрузку Linux/Y2Linux, аудиоустройство и драйверы, оценить ресурсы Rust-модели и стоимость офлайн-рендера с 12-периодным прогоном эффектов, затем решать перенос и интеграцию колеса/экрана.

Пока отсутствуют Synth 2, AI Generate All, интерфейс на реальном дисплее Y2, сохранение проектов на диск и доказанная production real-time безопасность. Евклидов секвенсор для высоты/длительности обсуждался, **но в работающий тракт не интегрирован**.
