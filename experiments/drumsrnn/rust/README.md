# DrumsRNN Rust checkpoint loader (experiment)

This crate is **only an offline weight loader**, not a music generator or a Y2 firmware image.

The weights must already exist from the repository's `experiments/drumsrnn/download-model.sh`.
The loader reads `config.json`, `weights_manifest.json`, and all referenced binary
shards; checks lengths, tensor names, shape overflow, float32 dtype and finite data;
then decodes actual weights into Rust `Vec<f32>` tensors.

## Run from the Y2Synth repository root

```bash
cargo test --manifest-path experiments/drumsrnn/rust/Cargo.toml
cargo run --release --manifest-path experiments/drumsrnn/rust/Cargo.toml
```

To override the default checkpoint path:

```bash
cargo run --release --manifest-path experiments/drumsrnn/rust/Cargo.toml -- /path/to/drum_kit_rnn_tfjs
```

Expected for the checkpoint already inspected on Mac:

- 16 tensors
- 2,967,850 float32 elements
- 11,871,400 decoded weight bytes (11.32 MiB)
- attention length 32

**Not yet implemented:** LSTM inference, attention inference, temperature sampling,
rhythm generation, sample synthesis, runtime performance benchmarks, cross-compilation,
and running on Innioasis Y2. Loading and decoding all weights consumes more RAM than
the binary file size; the implementation minimizes temporary shard buffers but makes
no claim about embedded memory suitability yet.

The standard-library test fixtures are synthetic; do not mistake a passing unit test
for confirmation that the complete real checkpoint loads. `cargo run` against the
real, already downloaded checkpoint is the next smoke test.

No model weights are committed to Git. `Cargo.lock` for this executable will be
generated by Cargo on the first local build and should subsequently be committed for
reproducible dependency resolution.
